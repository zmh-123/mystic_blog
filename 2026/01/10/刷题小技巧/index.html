刷题小技巧

发表于2026-01-10|更新于2026-03-30|小技巧
|总字数:2k|阅读时长:7分钟|浏览量:

在刷题（尤其是 ACM 模式）的过程中，很多时候卡住我们的不是核心算法，而是一些 C++ 的输入输出细节、API 的特殊机制或者容易被忽略的边界条件。本文整理了我在刷题过程中遇到的一些“坑”和常用模板，希望能帮助大家避雷。

一、链表篇

1. 增长链表的操作

在构建新链表时，容易忘记指针的移动。

// 假设 head 为头节点，tail 为尾节点，sum 为计算结果
if (head == nullptr) {
    head = tail = new ListNode(sum % 10);
} else {
    // 关键点：先创建节点，再将当前指针的 next 指向它，最后移动 tail 指针
    tail->next = new ListNode(sum % 10);
    tail = tail->next; // 别忘了这一步！将 tail 移动到新节点
}

二、ACM 模式输入输出篇

1. 读取带空格的整行字符串

当需要读取包含空格的字符串时，不能使用 cin >> s，而要用 getline。

注意事项： 如果在 getline 之前使用了 cin >> n 等读取操作，输入缓冲区会残留一个换行符 \n，导致 getline 读到一个空行。

int n;
cin >> n;
cin.ignore(); // !重要：忽略输入 n 后的换行符

vector<vector<string>> logs(n, vector<string>(4, ""));
for (int i = 0; i < n; ++i) {
    string line;
    getline(cin, line); // 读取整行
    // ... 后续处理
}

2. 未知组数的连续输入

题目描述：1 <= T <= 10，确切组数未知，需读到文件结尾。

vector<string> password;
string code;
// 只要能读入 code 就继续循环
while (cin >> code) {
    password.push_back(code);
}

3. Vector 的初始化陷阱

千万注意： 如果不初始化 vector 的大小直接用下标访问（如 cin >> heights[i]），会报 段错误 (Segmentation Fault)。

// 错误写法：vector<int> heights;
// 正确写法：初始化大小
vector<int> heights(studentnum); 

for(int i = 0; i < studentnum; i++) {
    cin >> heights[i];
}

补充： 如果预先分配了空间，用 cin >> v[i]；如果没分配空间，必须用 v.push_back()。

4. 字符串数组排序

vector<string> 可以直接用 sort 进行字典序排序。

sort(brothers.begin(), brothers.end()); // 自动按字典序排序

5. 递归终止条件

写递归时，第一件事就是写终止条件，否则会导致栈溢出。

if (startpre >= endpre) {
    return nullptr;
}

6. 进制转换技巧

十进制转二进制（利用 bitset）：

#include <bitset>
// 将 nums2[i] 转为 8 位二进制
bitset<8> erjinzhi(nums2[i]);

二进制转十进制（利用 stoi）：

// 第二个参数 nullptr，第三个参数 2 代表二进制
int sum0 = stoi(result[0], nullptr, 2);

7. 处理单行输入，以空格分隔，换行结束

有时候不知道一行有多少个数字，可以使用 cin.peek() 检查下一个字符。

vector<int> nums;
int num;
while (cin >> num) {
    nums.push_back(num);
    // 检查下一个字符是否为换行符
    if (cin.peek() == '\n') {
        break;
    }
}

注意： 一定要先 push_back 再检查 break。

8. 更复杂的输入处理 (stringstream)

对于混合类型的输入，或者一行数据包含多个字段的情况，推荐使用 getline 配合 stringstream。

// 例如输入： "a b 2"
string line;
getline(cin, line); 
stringstream ss(line);
string u, v;
int t;
ss >> u >> v >> t; // 自动按空格分割并转换类型

9. to_string 的坑

to_string(s[0]) 是将字符的 ASCII 码 转为字符串，而不是字符本身。

  • 错误：to_string('a') 结果是 "97"
  • 正确：如果要取子串，用 s.substr(0, 1)。

三、动态规划篇 (Dynamic Programming)

1. 背包问题总结

  • 01 背包（一维数组）：
    • 遍历顺序：先遍历物品，再遍历背包。
    • 关键： 背包容量 j 必须 倒序 遍历，防止物品被重复添加。
    • 公式：dp[j] = max(dp[j], dp[j - weight[i]] + value[i])
  • 完全背包（物品可重复取）：
    • 遍历顺序：背包容量 j 正序 遍历。
    • 求组合数（顺序无关）： 外层遍历物品，内层遍历背包。
    • 求排列数（顺序相关）： 外层遍历背包，内层遍历物品。
  • 求装满背包的方法数：
    • 公式：dp[j] += dp[j - nums[i]]
  • 求凑足金额的最小硬币数：
    • 初始化：dp 数组初始化为 INT_MAX。
    • 公式：dp[j] = min(dp[j], dp[j - coins[i]] + 1)

2. 打家劫舍

  • dp[i]：考虑下标 i 之前的房子能偷到的最大金额。
  • 公式：dp[i] = max(dp[i - 2] + nums[i], dp[i - 1])

3. 股票买卖

  • dp[i][0]：第 i 天 持有 股票的最大现金。

  • dp[i][1]：第 i 天 不持有 股票的最大现金。

  • 递推（买卖一次）：

    dp[i][0] = max(dp[i-1][0], -prices[i]); // 注意这里是 -prices[i]
dp[i][1] = max(dp[i-1][1], dp[i-1][0] + prices[i]);

4. 子数组 vs 子序列

  • 子数组 (Subarray/Substring)： 连续。dp[i][j] 通常表示以 i-1 和 j-1 结尾 的结果。
  • 子序列 (Subsequence)： 不连续。dp[i][j] 表示范围 [0, i-1] 和 [0, j-1] 内的最长公共子序列，不一定以末尾字符结尾。

四、BFS (广度优先搜索) 篇

1. 多源 BFS 更新逻辑

在多源 BFS 中，不用每次判断 visited，而是通过比较距离来更新：

// 只有当发现更短路径时才更新并入队
if (distance[nextx][nexty] > distance[curx][cury] + 1) {
    distance[nextx][nexty] = distance[curx][cury] + 1;
    que.push({nextx, nexty});
}

2. 按层遍历（计算步数/时间）

如果题目要求计算“第几步”或“时间”，必须按层处理队列。

while (!que.empty()) {
    int cursize = que.size(); // !关键：固定当前层的节点数量
    for (int i = 0; i < cursize; ++i) {
        auto node = que.front();
        que.pop();
        // 处理当前节点...
        // 将下一层节点加入队列...
    }
    time++; // 遍历完一层，时间+1
}

五、优先队列 (Priority Queue) 篇

priority_queue 是刷题神器，但排序规则容易搞混。

1. 基本定义

// 默认是大顶堆（降序），顶部是最大值
priority_queue<int> pq; 
// 等同于
priority_queue<int, vector<int>, less<int>> pq;

// 小顶堆（升序），顶部是最小值
priority_queue<int, vector<int>, greater<int>> pq;

2. 自定义排序规则

注意： 优先队列的 cmp 逻辑与 sort 是 相反 的。

  • sort 的 cmp(a, b) 返回 true 表示 a 排在 b 前面。
  • priority_queue 的 cmp(a, b) 返回 true 表示 a 的优先级 低于 b（即 b 排在 a 前面/上面）。

Lambda 写法：

auto cmp = [](int node1, int node2) {
    // 想要小顶堆（小的排前面），这里要返回 true 当 node1 > node2
    return node1 > node2; 
};
priority_queue<int, vector<int>, decltype(cmp)> que(cmp);

结构体重载操作符写法：

struct Node {
    int value;
    // 重载 < 运算符
    // 如果想要大顶堆，逻辑保持正常 (return this->value < other.value)
    // 如果想要小顶堆，逻辑需要反过来
    bool operator<(const Node& other) const {
        return value > other.value; // 小顶堆：值越小优先级越高
    }
};
priority_queue<Node> pq;

六、其他常用技巧

  1. 并查集： 使用前一定要记得调用初始化函数 init()。

  2. While 循环死循环： 写 while(left < right) 时，循环体内一定要有 left++ 或 right--。

  3. 内存超限： 递归过深或队列堆积。检查递归终止条件，或者在 BFS 中是否重复添加了已访问节点。

  4. 回溯路径逻辑：

    如果使用数组记录路径（如 parent[curr]），回溯时不要写成 curr = parent[curr] 后没有终止条件，容易死循环。

总结： 细节决定成败。建议在做题前先通读一遍这些容易踩坑的点，尤其是输入输出处理和数据结构的初始化，能省去大量 Debug 的时间。祝大家刷题愉快，Offer 多多！
