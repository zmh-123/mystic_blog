无线表格识别系统（基于qwen）

写在之前

前两天帮女朋友整理一些底物，就是将一些手写的数据手动输入到Excel中，整理的过程不免繁琐，刚好最近也不是很忙，想着能不能找个项目部署下来用程序完成这些操作。

放在以前我可能会翻很多博客最后也是以失败告终，不过前几天听了trae的一个宣传（虽然没有当时还没有solo的名额），所以就想着用trae来完成这么一个项目，从写需求到选技术栈再到项目动起来其实也就不到一个晚上的时间，AI的快速发展越来越让我瞠目结舌了。

实际需求

这个项目的诞生源于一个实际需求：在化学实验数据处理中，经常需要识别底物和CAS号信息并快速写入Excel。传统的表格识别工具对无线表格的识别效果并不理想，而国外的大模型服务又存在访问限制和成本问题。于是，我决定利用国产大模型的优势，开发一个专门用于无线表格识别的工具。

技术架构

核心流程

整个系统的处理流程非常清晰：

图片输入 → 预处理 → 国产模型识别 → 数据解析 → Excel输出

技术栈选择

  • 编程语言: Python 3.8+
  • 图像处理: Pillow + OpenCV
  • 表格生成: OpenPyXL
  • 国产大模型: 通义千问（DashScope）
  • 界面框架: Tkinter（Python内置GUI库）

架构设计

  1. 模块化设计: 系统分为四个核心模块

    • ImageProcessor: 负责图像预处理和优化
    • TableRecognizer: 集成多个国产大模型API
    • ExcelGenerator: 生成标准的Excel文件
    • Utils: 工具函数和错误处理

  2. 多模型支持: 同时支持三大国产大模型，用户可根据需求选择

  3. 双模式操作: 提供图形界面和命令行两种使用方式

3. 智能数据解析

大模型返回的数据格式可能不一致，系统需要智能解析：

def parse_table_data(self, raw_result: Dict[str, Any]) -> List[List[str]]:
    """解析模型返回的原始数据"""
    try:
        # 尝试多种可能的JSON结构
        if 'table' in raw_result:
            return raw_result['table']
        elif 'data' in raw_result:
            return raw_result['data']
        else:
            # 尝试直接解析为二维数组
            return self.extract_2d_array(raw_result)
    except Exception as e:
        raise TableRecognitionError(f"数据解析失败: {str(e)}")

4. Excel文件生成

将识别结果转换为标准的Excel文件：

def generate_excel(self, table_data: List[List[str]]) -> str:
    """生成Excel文件"""
    wb = Workbook()
    ws = wb.active
    
    # 写入表头
    if table_data:
        headers = table_data[0]
        for col, header in enumerate(headers, 1):
            ws.cell(row=1, column=col, value=header)
            ws.cell(row=1, column=col).font = Font(bold=True)
    
    # 写入数据
    for row_idx, row_data in enumerate(table_data[1:], 2):
        for col_idx, cell_data in enumerate(row_data, 1):
            ws.cell(row=row_idx, column=col_idx, value=cell_data)
    
    # 自动调整列宽
    self.auto_adjust_column_width(ws)
    
    return output_path
