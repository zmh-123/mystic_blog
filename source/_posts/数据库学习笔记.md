## 介绍：数据库是什么，为什么要有数据库

数据库本质上就是一个**运行在硬盘上的文件系统**，一般我们自己编写的代码，数据存在List/Map里面，断电或者重启数据就没了，另外普通文件存在硬盘里面，比如说txt或则excel，能保存但是很难查找。而数据库（MySQL）中的数据存在硬盘里，但有一个管家管着，利用索引技术，很快就能找到。

可以用excel来类比下关系型数据库：

| **数据库术语**        | **Excel 对应**              | **说明**                                        |
| --------------------- | --------------------------- | ----------------------------------------------- |
| **Database (数据库)** | **一个 Excel 文件 (.xlsx)** | 比如 `meituan_data.xlsx`                        |
| **Table (表)**        | **Sheet (工作表)**          | 一个文件里可以有“用户表”、“订单表”、“商品表”    |
| **Column (列/字段)**  | **表头 (第一行)**           | 规定了每一列存什么，比如 `Name`, `Age`, `Price` |
| **Row (行/记录)**     | **数据行**                  | 每一行就是一个具体的订单或用户                  |

然后要说明的是，这里是MySQL的学习笔记，另外还有Oracle或者其他一些自研数据库管理工具自行学习即可。

## 环境配置

**1.下载MySQL**

[]: dev.mysql.com/downloads/installer/

建议下载大的那个，另外不用登陆Oracle账号，遇到直接跳过即可

**2.安装**

密码自己设置默认端口号是3306

**3.下载图形化工具DBeaver**

下载地址：dbeaver.io->Windows Installer，一路next即可

**4.建立连接**

> 装好后，我们要测试一下能不能连通。
>
> 1. 打开 DBeaver。
> 2. 点击左上角的插头图标 (New Database Connection)。
> 3. 选择 **MySQL** -> Next。
> 4. 填写信息：
>    - Server Host: `localhost` (本机)
>    - Port: `3306`
>    - Database: (留空)
>    - Username: `root`
>    - Password: `你刚才设置的密码`
> 5. 点击左下角的 **"Test Connection" (测试连接)**。
>    - *如果是第一次，DBeaver 会提示下载驱动 (Driver)，点 Download 即可。*
> 6. 如果弹出提示 **"Connected"** (连接成功)，就表明连接成功了。

**5.报错提示**

如果你测试连接的时候报错了，出现了Public Key Retrierval is not allowed，别慌，这是一个经典坑，在刚才那个连接配置界面，点击 **“驱动属性”** (Driver Properties) 标签页 -> 找到 `allowPublicKeyRetrieval` -> 把它的值改成 `TRUE`。一般来说就可以解决了。

## MySQL基础与单表查询

> 这一阶段主要掌握以下内容：
>
> **概念：** 库、表、列、行、主键、自增。
>
> **CRUD：** `INSERT`, `DELETE`, `UPDATE`, `SELECT`。
>
> **进阶查询：** `WHERE`, `ORDER BY`, `LIMIT`。
>
> **统计分析：** 聚合函数 (`SUM`, `AVG`, `COUNT`) 与 `GROUP BY` 分组。

### 建库建表

**1.创建数据库：**新建->数据库，name自定义，我这里是test1，其他默认。

**2.创建表**：展开test1，邮件点击新建表，创建一张用户表users。

**3.设计列（相当于画表头）----关键**：

在列（Columns）区域右键 -> **新建列 (Create New Column)**，依次添加以下 3 列：

**列名：`id` (用户ID)**

- **类型 (Data Type):** `INT` (整数)。
- **关键设置：** 勾选 **主键 (Primary Key)** 和 **自增 (Auto Increment)**。
  - *解释：主键相当于身份证号，表示它是唯一的。自增意味着你不用管它，数据库会自动填 1, 2, 3...*

**列名：`username` (用户名)**

- **类型:** `VARCHAR` (可变长字符串)。
- **长度:** 写 `50` (表示最多存50个字)。

**列名：`balance` (余额)**

- **类型:** `DOUBLE` 或 `DECIMAL` (小数)。

**4.保存：**创建完成，点击执行。
